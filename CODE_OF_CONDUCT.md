# Code of Conduct

We are committed to a respectful, harassment-free community. Be considerate,
focus criticism on work rather than people, respect privacy, and avoid sharing
personal information. Reports should be made through the private contact
channel configured by the eventual public repository after double-blind review.

During review, this anonymous artifact intentionally publishes no personal
contact address. Urgent security matters should use PyPI's private vulnerability
reporting path once the project page is active.
