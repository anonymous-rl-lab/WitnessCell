# Han2017：论文相关实验汇总与精简复现

论文基准：v36；代码发行：28.0.0。目标研究为 Han K562；HeLa、A549、293T 是来源模型的训练背景。此次整理没有重新训练模型或改动论文数值。

## 保留的科学问题与设计

在目标单扰动相加基线上，使用冻结的 SF12/V4 共享函数产生伙伴方向，再仅用允许的目标组合测量选择幅度。全量重建面板含 20,359 对、两份真实重复；发表聚合面板含 20,791 对。两种读出均有五套三折划分，每个完整无序组合的测量同属一侧。六个来源配置、零修正、未调幅和其他原协议对照均保留。

控制输出为 `B + alpha * P_Q D`，查询结局不参与 alpha 估计。该全量适配的新增向量已是伙伴分量，因此它检验目标侧调幅，不单独证明分量控制优于整体缩放。来源方向与目标基线的适配、全部十二个 SF12 特征和 V4 结构见论文 SI S44–S52 及冻结源码。

## 原主分析与后续扩展

原协议把共同身份上的秩一比较列为 primary，全量 SF12/V4 为共享函数扩展。原主分析的重建读出相对未控制有止损，相对关闭伙伴仍为负；准确逐行结果在 `snapshot/results/PRIMARY_COMMON_RANK1.csv`，协议在 `snapshot/PROTOCOL.json`。SI Table S49 保留分析状态。本整理保留这个必要记录，不恢复更早迁移试验的主文图，也不以全量扩展替换原协议身份。

## 精简方式

保留压缩 guide 计数、发表工作表、完整注释坐标、分折身份、全部模型、参数、代码锁、评分和必要协议；原模型和数据文件按字节原样保存。

移除独立存储的 **180 个可确定性生成的重复 NPZ**：120 个校准/查询测量切片和 60 个查询预测文件。恢复配方及每个原始 SHA256 在 `RECIPES.json`。本轮恢复后全部与原件逐字节相同。其余删去的六个文件是冗余叙述或运行日志，名称与原因在 `COMPACTION_LEDGER.json`。没有删除不利配置或原主分析结果。

## 运行

从代码总包根目录：

```bash
python -B tools/reproduce.py --task han --out ../han_replay_new
```

只检验无损恢复：

```bash
python -B experiments/han2017/materialize.py --out ../han_restored_new --mode exact
```
