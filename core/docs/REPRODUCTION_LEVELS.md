# Reproduction levels and precision contracts

1. **Stored artifacts.** `MANIFEST.json` verifies every release file by size and SHA256 (except the manifest itself). The original legacy manifest and scientific archives remain intact. `PAPER_BASELINE.json` locks the unchanged v36 manuscript files. The light package includes its own complete manifest.
2. **Han deterministic reconstruction.** `experiments/han2017/materialize.py` restores 120 fold outcome files and 60 query prediction files from retained identity lists, full arrays, frozen coefficients and the original transformation code. All 180 matched original file bytes in this run. `--mode exact` rejects a byte mismatch; `compatible` materialization alone is not numerical acceptance.
3. **Score reproduction.** Original per-operation metrics, saved RNA/functional predictions, sufficient statistics and decision records produce the reported tables. This does not rerun every competitor's preprocessing or original metric adapter. Numerical comparisons preserve each original method's aggregation and endpoint projection. The theory task rechecks the finite-family targets/lower bound and scores the saved 16,000 synthetic cases; it does not refit synthetic estimators.
4. **Han frozen inference.** The default Han task rebuilds the prepared outcomes/single effects from compact guide counts and the published workbook, restores frozen source functions, re-estimates target scalars and scores all 60 folds. It compares identities and arrays, then propagates observed prediction differences into coefficient and SSE bounds using the unchanged v36 comparator. `python tools/replay_han.py --out ../fresh --mode exact` additionally requires numerical identity. Default `compatible` was tested with PyTorch 2.10.0+cpu against the archive's recorded 2.15.0+cpu; SF12 matched, while V4 had small differences first observed at inference. Different environments are not proof of the underlying cause.
5. **Interfaces and training.** RNA, functional and control interfaces are retained. Artificial RNA interface tests may fit tiny examples; the default suite performs no biological predictor retraining. Full retraining sources and archived configurations remain in `legacy/` and `experiments/`, with external data/weight indexes where the original compact release used them. Training stochasticity is not covered by the byte-identity claim.
6. **Original reads.** Han count-stage replay is offline. Tens of gigabytes of FASTQ are not included. Retrieval/read-processing provenance remains in the snapshot; FASTQ-to-count reconstruction was not executed in this packaging run. Likewise the original large GSE neural weights/raw prediction assets are indexed, not all copied into this compact release.
7. **Figures.** All five main and five supplementary plots are redrawn from preserved numeric data, with checks on plotted Han tables and page bounds. PDF metadata, font engines and SVG identifiers can vary across environments, so redraw PDF byte identity is not required. The light package's original published-ready PDFs/SVGs are copied unchanged.

The original analyses remain distinct: core benchmark results do not become control-layer results; Shen component preservation and Han target-side scalar calibration test different operations. Full Han is a later shared-function extension. The original common-identity rank-one primary is retained with its result and qualification; it is not relabelled as an untouched confirmation.
