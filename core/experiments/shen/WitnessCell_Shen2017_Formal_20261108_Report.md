# WitnessCell：Shen2017 正式实验完成报告

完成日期：2026年11月8日（UTC+8；机器日志保存UTC时间）。

**已取得原始计数，完成三种细胞的真实拟合与正式留出评价。预设主秩一模型改善了完整响应预测，但没有改善端点消去后的伙伴预测。**

## 1. 本轮结论

以下均比较相同允许训练数据上重新拟合的 M0。误差降低为正代表改善，为负代表误差增加。

| 细胞 | 训练组合 | 留出组合 | 完整响应误差降低 | 伙伴误差降低 |
|---|---:|---:|---:|---:|
| HeLa | 2,096 | 523 | **4.1613%** | **−1.0995%** |
| A549 | 2,100 | 525 | **3.6498%** | **−0.1092%** |
| 293T | 2,056 | 517 | **6.1823%** | **−0.5265%** |

预设三细胞等权平均伙伴增益为 **−0.5784%**。10,000次共享端点权重扰动得到的中央95%范围为 **[−1.8696%, +0.6543%]**。这是固定预测、固定投影下的条件敏感性范围，不是跨研究或生物学总体的置信保证。

因此，本轮没有获得伙伴能力跨来源增益的阳性确认。完整响应的正向结果仍成立，但不能替代伙伴主终点，也不等于与 GEARS、Scouter 等方法完成了新的竞争比较。

已成功下载出版社 S1、S2 和作者原始分析代码 ZIP。S2 的实际两个工作表分别是构建设计和汇总统计，并没有提供本协议所需的逐重复、逐时间点原始计数。

随后检查了作者官方仓库的完整历史。原始计数保存在 **2017年3月6日的提交 `7c05a5a551dc5cd3a3c841d2f22215a450b353a3`** 中，并在3月31日软件重组时移出了这些路径。最终使用四个原始文件：

| 历史计数文件前缀 | 本轮使用的样本 |
|---|---|
| `20160403_Hela_CV4` | HeLa，第3、14、28天，重复1/2 |
| `20160510_A549` | A549，第3、14天，重复1/2 |
| `20160627_HeLa_A549_CV4` | HeLa第21天；A549第21、28天，重复1/2 |

每个样本有24,908条构建计数，24个样本共 **597,792条记录**。其中每个样本保留599个双阴性对照构建。S2A设计中有600个双阴性对照记录，少的一个没有被补造。

A549选定的八列计数与作者原始评分输入中的24,309个共有构建**全部逐值相同**。早期文件中另有A549第28天列，本轮按照作者评分输入采用后一次测序文件的第28天列；这一取舍在任何模型拟合前固定，与预测成绩无关。

全部原文件SHA256、Git对象标识、固定提交下载地址及逐列映射见 `measurement/SOURCE_PROVENANCE.json`。没有把作者全图拟合的单基因效应、GI分数或显著性筛选后的网络边作为模型输入。

## 3. 原协议如何执行

模型、参数网格、质控阈值、划分盐值和主终点均保持原方案。15个随包Python科学源模块与烟测包逐字节一致。源文件位置由“待核对S2”落实为“官方历史计数＋S2A注释”，未更换目标或估计器。

每个构建、每个重复分别拟合相对于当时双阴性对照均值的log2计数增长斜率，单位为每天。低于20 reads的时间点剔除；至少保留三个时间点。两个重复之间使用共同合格的物理构建，每个基因组合至少三个，共同构建等权平均。单扰动只由基因＋阴性对照构建得到。

先对2,628个物理基因对固定身份划分：名义训练2,102对、查询526对；然后做测量质控，缺失对不替换。三种细胞共享物理身份划分。质控后HeLa、A549、293T分别保留2,619、2,625、2,573个组合，均保留73个有单扰动测量的端点。

HeLa源内烟测只使用外层训练池，另留出211个组合作技术检查。烟测完整增益为+1.5313%，伙伴增益为−2.7691%；是否继续正式运行按数值有效性决定，没有设置成绩必须为正的门。随后三种细胞的正式模型独立重新估参，全部预测SHA固定之后才开启正式评分。

主方法是冻结的signed rank-one。内层三折按完整响应SSE选择参数，同时保留零修正。不能在看到伙伴评分后切换为伙伴损失调参。次要谱模型和单扰动相加均一并保留。

三个正式上下文的拟合耗时约4.10、3.42、4.22秒，合计约11.73秒；主要工作耗时在源文件恢复、映射、核验和打包。这是73端点的小型功能模型，不是重新训练大型神经网络。

## 4. 全部结果及解释

### 次要模型

| 细胞 | 谱模型完整增益 | 谱模型伙伴增益 | 单扰动相加完整增益 | 单扰动相加伙伴增益 |
|---|---:|---:|---:|---:|
| HeLa | +3.8729% | −4.4024% | −179.4163% | −0.0083% |
| A549 | +2.6960% | −1.1081% | −114.7367% | +0.7664% |
| 293T | +5.8017% | −3.0554% | −146.9340% | +0.1074% |

这些比较全部相对于M0，不是彼此相对的百分比。单扰动相加缺少组合训练中拟合的端点细化，完整误差明显更高；其伙伴评价接近M0并不矛盾。

### 重复与条件敏感性

| 细胞 | 主模型伙伴增益：重复1 | 重复2 | 条件中央95%范围 |
|---|---:|---:|---:|
| HeLa | −0.8402% | −1.3027% | [−4.0588%, +0.9347%] |
| A549 | −0.9093% | +0.6720% | [−2.2857%, +2.6105%] |
| 293T | −1.3684% | +0.1921% | [−2.9607%, +1.4235%] |

所有重复与细胞均保留。它们来自同一外部研究，不是三个独立研究；不同细胞还共享查询基因对，不能把留出行数之和当成独立生物重复数。

### 为什么完整响应改善而伙伴没有改善

预测固定后的正交误差分解显示：三组完整误差的下降均来自端点投影成分，其收益被伙伴成分的小幅误差增加部分抵消。秩一修正本身确实改变了伙伴方向，伙伴部分分别占其查询修正能量约23.33%、37.50%、25.60%；因此问题不是“这条分支数学上无法改变伙伴”，而是它在本来源没有学到有用的留出伙伴修正。

在本轮定义的、等构建权重的查询读出上，完整响应两重复相关为0.393、0.421、0.488；去端点后分别为0.093、0.114、0.006。这是预测固定后计算的诊断，提示当前测量目标的伙伴信号重复性弱。它不能证明噪声是唯一原因，也不是“任何模型都不可能学习”的信息下界。这里的读出不同于作者的效率加权、全图拟合GI估计，不应把相关性直接归为原论文整体实验质量。

本轮结果支持继续区分“完整预测改善”和“新增伙伴收益”。同时，它表明仅有约两千个训练组合还不足以保证当前学习器获得伙伴增益，不能据此提出或维护一个通用组合数量门槛。

## 5. 独立核验与重放

独立脚本没有调用本包的斜率、聚合或评分函数：用充分统计量重新拟合原始计数斜率，再以最小二乘投影重新计算全部误差。

- 82项独立检查全部通过；最大测量重建差为 `1.951563910473908e-16`，最大增益差为 `2.220446049250313e-16`。
- 每组24项内层目标次序检查均通过，全部16个候选配置数值合格，最终模型均收敛。
- 已从新目录重新执行测量准备、三组拟合和评分；9个主预测数组（3细胞×M0/秩一/谱）与正式档案的最大绝对差均为0。
- 原始输入、划分、模型参数、内层成绩、固定预测、真值及评分齐全。重放只验证可复现性，不增加独立科学证据。

本轮是本地协议冻结后的新来源评价，不是外部预注册。测量准备程序需要读取原始查询计数以构造评价目标；模型拟合只接收训练结局和查询身份。这个软件隔离不是机构级盲法。

## 6. 复现入口和文件

在解压目录安装 `requirements.txt` 中依赖后：

```bash
python code/independent_audit.py
python code/replay_formal.py --out /tmp/shen_replay_fresh
```

第二个命令要求一个不存在的新目录，重新从计数准备输入并拟合，不覆盖正式预测。重新绘图：

```bash
python code/make_result_figure.py
```

主要文件：

- `source/`：四个实际使用的历史原始计数、作者代码ZIP、出版社S1/S2及来源回执。
- `measurement/`：统一计数表及列映射。
- `prepared/`：固定划分、质控、训练输入、查询真值。
- `runs/formal/`：三组模型、内层选择与固定预测；`PREDICTIONS_FROZEN.json`记录统一冻结。
- `results/formal/SCORES.json`：正式全部评分。
- `audit/INDEPENDENT_SCORES.csv`、`INDEPENDENT_AUDIT.json`、`NUMERICAL_REPLAY.json`：独立复算与重放。
- `figures/Shen2017_Formal_Results.png`和`.svg`：结果图。
