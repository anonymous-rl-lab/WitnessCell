# WitnessCell：模型恢复、Shen–Jurkat诊断与有限改进实验

日期：2026-11-08。性质：回顾性开发，原始正式结果不变。

## 1. 本轮结论

12参数模型 SF12、可训练伙伴网络 v2/v4 和 FullFeedback 源码都已恢复。本轮已经实际重拟 SF12 和 v4 的功能读出适配，并比较 Next2 投影／幅度校准思想、非线性特征、训练组合响应特征和秩一模型。没有重新训练 GEARS、Scouter 或 FullFeedback。

结果支持两点：Jurkat 的伙伴预测仍有改进空间；Shen 当前重建读出上的问题，不能仅靠增加组合数量或网络容量解决。Shen 三组没有取得共同的、可靠的伙伴预测突破。

所有增益以下降误差为正，相对于同一数据上重新拟合的原 M0。新模型均在原始查询身份上评价，未更改查询结局、删除不利组合或使用外层成绩挑选主模型。

| 数据 | 原秩一伙伴增益 | 新方案伙伴增益 | 新方案完整响应增益 | 训练侧选中的方案 |
|---|---:|---:|---:|---|
| HeLa | −1.0995% | +0.4856% | +0.2435% | 单扰动乘积特征，投影后校准 |
| A549 | −0.1092% | +0.1147% | +3.1663% | 分开校准原秩一的端点与伙伴部分 |
| 293T | −0.5265% | −0.5948% | −0.8032% | SF12；训练侧小增益未延续 |
| Jurkat | +6.1750% | +7.2794% | +6.7349% | 固定非线性特征，投影后校准 |

主方案由两批候选的三折训练侧预测误差合并选择，然后才评分新外层预测。此处“固定非线性特征”不等于可训练网络。完整结果包括所有已选模型分支，而非仅保留上表的最好结果。

Jurkat 两次重复的增益分别为6.36%、8.39%，逐一删除79个端点后仍为正，范围5.61%–8.39%。但是，新方案超过原秩一约1.10个百分点的差异，描述性区间跨零；因此只能报告更好的点估计，不能宣称已证明显著胜过旧模型。HeLa 的伙伴收益描述性区间也跨零。

## 2. 找回了哪些模型，实际用了什么

| 家族 | 恢复内容 | 本轮使用状态 |
|---|---|---|
| SF12 | 原12特征构造、归一化岭拟合、训练投影、查询预测代码 | 保留原特征构造，重新拟合标量生长读出；原RNA幅度系数未照搬 |
| Next2 RNA R | 对称乘积核、训练／查询投影、训练重复收缩、受完整误差约束的幅度优化 | 移植投影与幅度优化；增加有限的功能特征候选，属于功能适配 |
| R-G | 关系模型及模式输入代码 | 需要被干预基因的RNA读出；没有把标量fitness伪装成RNA关系图 |
| 神经伙伴 v2 | 模型、训练入口、原选中检查点 | 本轮仅恢复；未重新训练v2 |
| 神经伙伴 v4 | 模型、训练入口、源编码器及伙伴头检查点 | 使用原PartnerHeadV4类，实际重训功能伙伴头；旧RNA源编码器和RNA权重未直接用于fitness |
| FullFeedback | model.py、train.py、测试、原始模型实现 | 本轮仅恢复；尚未进行Shen训练 |

v4保留原对称双端点预测头，共8,517个参数；此功能适配关闭RNA额外特征，使用固定GenePT64、单扰动生长读出及中性的标量读出向量。它不是原RNA完整网络在Shen上的零适配重放。

GenePT覆盖Shen全部73个端点。Jurkat的PET112按NCBI映射到GATB；SKIV2L在现有嵌入表中缺失，采用源嵌入总体均值，缺失状态已记录。没有用结局补齐嵌入。

| 数据 | SF12伙伴增益 | v4伙伴增益 | v4不做幅度校准 |
|---|---:|---:|---:|
| HeLa | −0.1668% | +0.0037% | −16.5007% |
| A549 | 0（训练侧选择零修正） | +0.0007% | −5.5377% |
| 293T | −0.5948% | −0.0261% | −22.5903% |

这次真正的神经网络已完成训练，并非用固定tanh/SiLU特征冒充。其表现说明幅度控制很关键，但把修正压到几乎零是抑制损伤，不能当成伙伴学习成功。

## 3. Shen与Jurkat的差别在哪里

### 3.1 组合覆盖相近，可重复的伙伴信号差异很大

以下只用训练部分。伙伴相关是在各自训练图上去掉自由端点贡献后，计算两个重复的相关。

| 数据 | 训练组合 | 端点 | 可用全部基因对中的训练比例 | 完整读出重复相关 | 伙伴重复相关 |
|---|---:|---:|---:|---:|---:|
| Jurkat | 2464 | 79 | 79.97% | 0.9144 | 0.4252 |
| HeLa | 2096 | 73 | 79.76% | 0.3820 | 0.0703 |
| A549 | 2100 | 73 | 79.91% | 0.3802 | 0.0719 |
| 293T | 2056 | 73 | 78.23% | 0.4977 | 0.0815 |

Shen不属于只有几十个组合的稀疏设置。其平均端点训练度约56–58，Jurkat约62，差别不足以单独解释目前的表现。低重复相关可能混合测量误差、构建体效力、处理方法和真实实验变异；不是信息论上限，更不是“任何方法都无法学习”的证明。

### 3.2 当前Shen读出的构建方法值得优先改进

当前正式目标为：每个构建体至少三个合格时间点，控制相对log2计数的线性斜率；在重复间匹配物理构建体后等权汇总。所有当前成绩仍对应这一冻结目标。

| 训练数据诊断 | HeLa | A549 | 293T |
|---|---:|---:|---:|
| 每组合共同构建体数中位数 | 8 | 8 | 7 |
| 构建体斜率两重复相关 | 0.1506 | 0.1711 | 0.2032 |
| 斜率线性拟合R²中位数 | 0.5495 | 0.6918 | 0.6363 |
| 合格构建体中仅有三个时间点的比例 | 43.95% | 7.93% | 15.38% |
| 训练双扰动原始计数低于20的比例 | 17.19% | 7.70% | 12.51% |
| 不同构建体半集的伙伴相关 | −0.0266 | −0.0534 | −0.0232 |

构建体半集诊断只保留至少六个共同构建体的训练组合，合并两实验重复后按身份哈希分半；三组分别有1909、1984、1684对。它检验的是当前读出对构建体选择的稳定性，不是独立生物学确认。不同构建体也可能共享guide，因此不能将其看作完全独立重复。

时间诊断也没有显示一个共同的“晚期就恢复”模式。HeLa的day3–21伙伴相关为0.1759，但只覆盖1140个训练组合；A549各时间终点约0.065–0.092，293T约0.064–0.089。不同终点的可用组合也不同，不能直接把最佳相关的时间点替换成原目标以宣称模型改善。

必须区分本次重建与Shen作者的处理。原文采用逐时间点过滤、构建体效应估计、guide效力加权及统计去噪；其单基因效应也利用整个组合设计估计，而当前单扰动只取允许的基因–NTC测量。原文显著互作的重复相关是在经过显著性筛选的条目中计算，不是全组合端点投影相关。因此，本轮结果既不能直接否定原论文的重复性，也不能拿其经过全图拟合的效应量直接训练未测组合预测器。

下一步值得检验的是：只用训练侧估计guide效力和测量可靠性，在每个内层拆分重新估计，然后比较模型是否更好地预测原始冻结查询读出。若重新定义测量目标，应另立并列实验，不能覆盖本轮结果。

### 3.3 原秩一模型优化的目标与伙伴目标不一致

原模型内层按完整响应误差选参数。它学到的矩阵修正同时含有端点部分和伙伴部分；前者足以改善完整响应。原Shen正式实验中，完整响应改善与伙伴退步并存正是这一现象。

对任意去端点误差e和新增伙伴修正d，误差减少为2〈e,d〉−‖d‖²。方向不对或幅度太大，都能使完整训练有效的修正在伙伴测试上失败。本轮分别尝试：直接优化投影后的损失、分开控制端点与伙伴幅度、加入固定特征与可训练网络。直接投影秩一也未在Shen取得共同收益，说明目标错位只是问题的一部分。

### 3.4 不能从复杂网络期待自动恢复弱信号

恢复的v4网络在不校准时使Shen伙伴误差增加5.54%–22.59%。训练侧选择的幅度为HeLa0.0822、A5490.0030、293T0.0399，因而显著减轻损伤。Jurkat则保留有用的修正，并取得双重复同向的增益。这里比较的是相同原始查询上的预测，不是训练损失。

## 4. 可以总结的规律

1. 组合数量和覆盖是必要的描述，不能替代伙伴信号的重复性。Shen反例否定了“超过约两千对就应当成功”的简单经验规则。
2. 先确定所需响应成分，再用同一成分选模型。完整误差下降不能自动说明伙伴学习成功。
3. 先验证低维、有约束的修正，再扩大网络。在本轮Jurkat，固定非线性特征和SF12优于当前v4功能适配；在Shen，大修正主要增加损伤。
4. 测量读出的构建属于方法问题的一部分。应先比较允许信息下的处理方法，再区分数据本身与模型的限制。
5. “条件性胜利”目前可落在Jurkat的可重复功能增量；HeLa是小幅正向线索，A549接近零，293T仍失败。没有得到通用阈值或新的独立确认。

## 5. 执行、核验与复现

两批候选都用原训练数据的相同三折。幅度选择沿用Next2的约束二次优化：降低伙伴SSE，同时训练侧完整SSE不高于M0，含零修正候选。此约束不保证外层完整误差不会增加。没有重新训练后依据外层成绩更换主方案。

恢复的SF12有效实现与原函数对照，最大预测差7.22×10⁻¹⁶；v4选中权重重新载入后，最大差5.56×10⁻¹⁷。原M0逐值匹配。投影恒等式、正控制、对称性、分块预测和冻结文件哈希也已核验。

原外层结果在此前已经查看，本轮属于开发。所有置信区间仅是固定预测、固定投影误差的组合重采样描述，不能涵盖共享端点、拟合和模型选择的不确定性。

- `code/fit_models.py`：第一批固定特征和秩一修正。
- `code/fit_recovered.py`：原SF12与真实v4伙伴头的功能适配。
- `code/evaluate_frozen.py`：冻结后独立评分。
- `code/check_and_sensitivity.py`：原代码等价、检查点重放及敏感性。
- `code/measurement_diagnostics.py`：训练侧计数和构建体诊断。
- `inputs/`：所有训练响应、查询身份、匹配GenePT64。
- `references/`：原始冻结预测、查询真值及原始计数；训练脚本不读取此目录。
- `results/`、`results_phase2/`：每折预测、选择、参数与检查点。
- `evaluation/`：全部外层结果及敏感性；`diagnostics/`为训练侧诊断。

在新目录重新训练、选型和评分：

```bash
python code/refit_all.py --output /absolute/path/to/new_run
```
