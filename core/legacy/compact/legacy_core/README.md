# E17/E18/E19/E24 精简复现模块

本模块保留论文所需的端点模型、双头模型、发布版模型消融及官方六指标比较。输入是原 v24 的**逐条件误差和逐操作原始指标**，CSV 经无损 gzip 压缩；没有将原始精度替换为论文中的四舍五入数字。阴性结果、所有数据集、所有拆分和全部符合原口径的竞争方法均保留。

```bash
python compact/legacy_core/run.py --out /tmp/witnesscell_legacy_replay
```

输出路径必须尚不存在，且位于本模块之外。依赖 Python 3、NumPy、pandas；运行会按原种子重新执行三个模型版本各 20,000 次的配对簇自助，并生成 `VALIDATION.json` 和重算表格。本次完整回放用时约 36 秒，无需 GPU。

## 可独立重算的内容

| 原实验 | 本模块内容 | 重算单位 |
| --- | --- | --- |
| E17 | 端点模型相对骨干的误差、官方排名与区间 | 654 个条件×种子；四数据集、三种子 |
| E18 | 双头模型相对骨干的误差、官方排名与区间 | 同上 |
| E19 | 发布版相对前一版及骨干的误差 | 同上；含所有负增益 |
| E24 | 发布版官方 Top-100 六指标、Top-5000 四指标、敏感性及区间 | 16 方法×654 操作×2 面板 |

每个官方排名版本从保存的原始指标重新计算每个操作内的指标排名、平均排名、最终操作排名、各数据集排名、各面板排名和跨数据集汇总。发布版的 6,540 行原始指标与汇总输入逐项交叉核对。簇自助采用原始 `aggregate_official_full.py`、原始随机种子 20260809 和 20,000 次抽样，按数据集分层，整组保留同一扰动的拆分种子记录。

主重算容差为绝对误差 1e-12。`SOURCE_MAP.json` 将每份压缩输入和算法源文件对应回原 v24 路径及 SHA-256；回放先验证解压后的字节与源文件完全一致。`VALIDATION.json` 记录本次已实际执行的源—精简结果比较。

## 明确的复现边界

这是**逐条件/逐操作指标层的精确回放**。它不是从原始细胞重新处理、重新训练模型或重新从基因级预测计算距离。原模型源码仍保留在 `source/`，原始运行器需要外部条件缓存、GEARS 资产及相应环境。原 v24 完整包是这些历史大数组的来源归档。

官方竞争者输入继承原发布基准的指标表，不声称在本精简包内重新训练了竞争者。原发布基准所采用的信息条件、训练预算和选择规则没有被本次清理改动。这里的汇总端点消融误差不是其他模块的加权 MSE 或伙伴增益，不能相互替换。

`data/ARRAY_CERTIFICATES.json` 是**构建本精简包时**实际解码、检查 36 个原始部署 NPZ 后产生的审计记录：包含数组名称、形状、dtype、SHA-256，及 4 个未启用发布修正的拆分与前一版预测完全相等的检查。该文件保留可追溯证据；默认回放不含原大数组，不会冒称重新执行了这些基因级相等检查。后续 E25–E32 由总代码包另行原样保存，本模块不修改它们。

## 删除和替代

`REPLACEMENT_INVENTORY.csv` 列出本模块四个原实验目录的文件处置。大体量的条件均值/方差缓存、重复的部署预测矩阵、六指标源压缩包和探索阶段结果不在本模块中重复捆绑。需要精确重算的逐条件误差、逐操作六指标、最终模型源码与比较脚本已保留；用小型中间输入重算汇总，而不是仅复制最终分数。

`source/v12_endpoint/`、`source/v13_dual/`、`source/v14/` 是对应论文消融的实际实现，不是保留完整开发历史。`probe_multhead_training.py` 虽有 probe 名称，仍是发布模型的有效导入依赖，因此保留。`source/aggregate_official_full.py` 来自原 E15，是排名与簇自助的真实计算依赖；不需要整个 E15 历史数据目录。

`tools/build_inputs_from_v24.py --source-root /path/to/grn_repo_v24 --out /new/input-directory` 可从完整原包及其 `reproduction_store` 重新生成本模块的压缩输入、未改动源码和构建时数组证书。它按需解码，不恢复全部大数据；需要原 v24 的存储工具及其 zstd 依赖。
