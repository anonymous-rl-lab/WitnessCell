# Prior execution and withdrawn-registration disclosure

## Withdrawn registration

An earlier registration at `https://osf.io/a2dfr` included a proposed 135-pair
K562 CRISPRa Perturb-seq experiment. That experiment was not authorized for
execution, no new cultures or libraries were produced and no outcome data were
collected. The registration was withdrawn before this v2 computational
registration.

The original record is not treated as though it had contained the present
purely computational protocol. The new v2 registration is a separate protocol
with a separate timestamp.

## Previously observed computational result

Before v2 registration, an exploratory AutoDL execution using the frozen v14
archive completed successfully. It regenerated 12 split archives with exact
array equality and reproduced the paired v14-versus-v13 summary. Because this
result was already observed, it is not counted as the v2 confirmatory outcome.

The v2 study prospectively constrains a new full execution after registration.
Its value is independent cross-environment confirmation under frozen inputs and
fail-closed criteria, not hypothesis discovery.
