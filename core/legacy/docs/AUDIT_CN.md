# v22 论文与 v25 精简复现覆盖核对

核对对象是当前 v22 的 `main.md`、`si.md`、`ED.md` 及图表源数据，而不是依据旧版实验编号推测重要性。`PAPER_COVERAGE.csv` 逐项列出 **7 张主图、10 张扩展数据图、19 张补充表**的来源、实验依赖与复现层级。源稿的 SHA-256 记录在 `PAPER_SCOPE_IDENTITIES.json`。

## 精简决策

E00–16 没有直接支撑当前 v22 数值图表的独立必需原始矩阵。大规模原始细胞输入、训练缓存、重复预测和历次版本记录可以从本次精简交付中移出，不能因此删除仍由当前模块引用的同名资产。尤其 E25 的完整 witness 复算仍依赖规范位置的 Wessels 条件聚合、评价数组及 GO/模型代码；这些资产应通过实测的依赖闭包保留，不能仅凭目录编号清除。

E19 的当前 v14 源码不依赖 E00–16 的训练脚本；它自己的 `probe_multhead_training.py` 是有效导入依赖，应保留。E20 的原登记 K562 失败记录、修订及结果身份仍支撑 SI6/S6，必须保留。E21/E22 的冻结风险阈值与逐查询记录仍支撑 SI5/S7，必须保留。早期开发史可以缩成来源与范围记录，但科学失败结果不能被后来的成功覆盖。

E25–32 已精简；本次建议不修改任何字节。论文桥只额外保存小型制图表和原始绘图脚本。它与 E25–32 的少量表格重复，换取旧脚本不变、图表可直接重建，未引入原始细胞矩阵。

## 论文图表桥

`publication/` 保存四个原绘图脚本，均与 v22 完整稿逐字节相同；同时保留这些脚本和补充表需要的压缩前约 4.8 MB 源数据。脚本自动执行 v22 的 Fig2/Fig3 置换与新版 Fig1/Fig7 构建，不保留旧 PDF、PNG、SVG 或 TeX 构建残留。

运行：

```bash
python publication/run.py --out /tmp/witnesscell_v25_paper_fresh
```

输出包括全部 17 张图的 PDF/PNG/SVG、源数组和表格算术检查结果，以及 `PAPER_REPRODUCTION.json`。输出必须位于模块外部的全新目录，避免改变冻结输入。`PUBLISHED_TABLES_v22.md` 是从当前 SI 提取的完整 S1–S19 原文比对目标。

## 复现层级必须保留的边界

- 图表重画不等于重新训练模型。桥内独立计算已有 11×4,995 RNA 对比误差、四角和差、Jurkat 双重复评分、发布划分数量等；对应模型复算由各实验模块承担。
- ED9/S11/S12 的原系统六划分扩展可从保留的 split-loss 表重新计算每划分比率和三种子几何汇总。当前桥没有完整的扩展预测数组与重新拟合入口，因此明确标为**表级算术复现**。不能把此桥宣称成该扩展的完整重训。
- E31 的独立 RNA primary 是归档统计审查；后续 Dixit 程序模型可从紧凑条件均值重新拟合。这两个结果身份不互换。
- E30 可重新解五个 SF12 共享系数系统，并由保存向量与损失统计复算结果；它没有虚构完整 RNA 输出向量。
- 全部保留数值均来自原论文/原实验；未运行新科学实验、未改变任何论文成绩或补造缺失预测。

`EARLY_EXPERIMENT_SCOPE.csv` 给出 E00–16 的处理范围；它是当前论文依赖判断，不应被解释为历史研究已无科学价值或无外部复现需求。
