WitnessCell fixed-reference program prediction: source confirmation v1
Prepared 2026-10-20 (Asia/Shanghai); effective freeze time is recorded in FREEZE.json.

PURPOSE AND EVIDENCE IDENTITY
Test whether the previously developed fixed-reference G2M program predictor improves prediction of unmeasured combinations in a new source. The selected source is Mathur et al., Combi-seq, Nature Communications 2022, DOI 10.1038/s41467-022-32197-0; large-screen GSE174695, parent GSE174696. This is a retrospective, workflow-frozen, cross-intervention-type RNA confirmation: chemical combinations in K562. It is neither new wet-lab work nor an independent genetic-double RNA confirmation. The model is refitted using only the allowed training conditions in the new source; numerical parameters learned on Dixit are not transferred.

PRIOR ACCESS
Source selection used public methods, sample names, experimental layout and gene identifiers. The downloaded count file remained unanalysed while these rules were prepared. No G2M values, condition expression means, model scores or outcome-driven exclusions were examined. The scoped access audit found no documented previous Combi-seq use; this is not proof of non-access by every team member. Adamson, DLD1 and Joung were excluded on design/metadata grounds before response scoring. Combi-seq was selected for matched controls, singles, a sufficiently redundant combination graph and three experiment runs. This is the final source for this confirmation; a negative score does not trigger a search for a replacement success in this run.

SOURCE ADAPTER
Use the official GSE174695 count matrix and sample metadata, preserving their hashes. Each sample is a barcoded pool, not an individual cell. Normalize each sample independently to 10,000 total reads and apply log1p. Never use global high-variable-gene selection, differential expression, outcome-selected programs or learned phenotype mappings. All published gene rows remain available for the endpoint representation. A zero-total, negative, nonfinite or inconsistent sample triggers a data integrity failure; it is not silently removed after scoring.

Use internal DMSO_DMSO samples as controls. Exclude sample IDs ending in _ctrlReadsPerGene from the principal analysis, because their precise relationship to the internal control is not established. Retain them in the source and exclusion ledger. Exclude homotypic two-drug samples (same chemical twice). Preserve the published spelling Imatininb as an internal identifier, with a human-readable annotation Imatinib; no hidden renaming changes the split.

The two injection channels implement simultaneous treatment. The methods specify a single chosen GR35 dose for each compound and different stock multipliers to compensate for mixing. Average the two channel orientations, when both exist, equally within each unordered condition and each run. Then average rep1, rep2 and rep3 equally to construct the principal condition mean. Matched singles are compound+DMSO from the same screen. All orientations and runs of an unordered double are assigned together to training or test. The analysis does not claim that numerical dose values were independently verified for every compound.

FROZEN CAPABILITY
Copy the prior fixed-reference source without scientific changes (frozen_reference_core.py, SHA256 25c8d38a6f1c73fa4b7e2ccdee3535d8b80a5c3abac24a4cdecf2887c4759032). Use its full-RNA measured-single symmetric product kernel, training-incidence residualization, training-trace scaling, scalar saturation baseline, and complete identity-only reference universe F of all distinct pairs of eligible endpoints. No labels from unmeasured reference pairs are used. F depends on the frozen endpoint universe, not the incoming request batch. The frozen NEW CAPABILITY is this correction G, now inserted into the complete information-matched system: principal prediction = endpoint-control baseline + G. The endpoint-only comparator uses exactly the same fitted baseline. Also retain scalar-saturation + G, the unchanged preceding stand-alone assembly, as a secondary compatibility result. Both assemblies and their roles are fixed before any new outcomes; the primary is never chosen between them on test scores. Since P_T X_T = 0, subtracting an endpoint-only training correction cannot alter the projected target learned by G.

Use the existing 54-symbol Seurat G2M registry, SHA256 ccd9e710ef7ef448c9234ca007ea02aef5c190157060d639d75b090b63b07895. Use the pre-existing Dixit gene-identifier dictionary solely for identifier conversion, without importing Dixit expression values. Include only unique mapped identifiers present in the new assay; at least 40 program genes must be eligible before expression access. All signs are +1; the target is the unweighted average of these readouts divided by the training-only per-gene condition standard deviation. This is a transcriptional program score, not a fraction of cells or a biological hit rate.

Training normalization uses only the control, measured single conditions, and allowed fitting combinations, exactly as in the prior core. Saturation alpha grid is 0, .02, .05, .1, .2, .5. Partner lambda grid is .1, 1, 10. Alpha uses the prior training loss rule; lambda uses pooled training-internal full-program prediction SSE of the PRECEDING scalar-saturation + G assembly, with a tie favoring larger lambda. This prior operator-selection rule is preserved even though the principal confirmation inserts that same G into the shared endpoint baseline. No new G2M shrinkage, rank, network, endpoint feature, reference population or ensemble is introduced.

SPLITS AND INFORMATION
Use one deterministic threefold outer partition of all eligible distinct unordered pairs: sort SHA256('CombiSeq_confirm_v1|' + pair_id), then deal round-robin into three folds. This rule is independent of expression. Within each outer training set use the original graph-only cycle3 inner algorithm and freeze its resulting assignments before expression access. Each held-out combination is removed in every run and orientation. Measured singles and controls are available in every fold, so this is a seen-endpoint / unseen-combination task, not extrapolation to an unmeasured compound.

CONTROLS
Report five methods on identical targets: measured-single additive; the unchanged core's scalar-saturation baseline; a training-combination endpoint-correction baseline; the preceding stand-alone scalar-saturation + G predictor; and the principal complete system, endpoint-correction baseline + G. The endpoint control receives the same pooled runs, singles, program, fitting-only scaling, alpha rule and inner folds. Its residual uses the incidence kernel X X'/2; noise grid .01,.03,.1,.3,1 is inherited from the existing system. A scalar correction strength gamma in [0,1] is fitted from the concatenated inner OOF residuals, separately for each noise; select its inner SSE minimum. This adds a strong, information-matched endpoint control and a shared backbone while leaving the candidate correction and its prior selection rule unchanged. No test-based choice of the best comparator or predictor is made.

PRINCIPAL ESTIMAND
Across all outer-held-out pairs, sum full G2M prediction squared errors. Principal gain = 1 - SSE(complete system: endpoint baseline + G)/SSE(endpoint-correction control). Also report gain relative to scalar saturation and measured additive, plus all secondary standalone results. Pair counts, fold sizes and all denominators are mandatory. Equal pair weights are used; sample count and run count do not create extra independent pairs.

PARTNER-SPECIFIC CHECK
Within each outer test fold, form P_Q = I - X_Q X_Q^+ from identities only and score P_Q(prediction-truth). Pool these squared errors across folds. This projection is an evaluation diagnostic; it is never used to construct a deployed query prediction. Report its rank/dimensions and gain relative to both controls. Do not count overlapping rectangles as independent observations and do not infer biological interactions merely from a nonzero residual.

REPEAT AND UNCERTAINTY REPORTS
Evaluate the same pooled-training predictions against each of the three separately retained experimental-run targets using the identical fitted scale. Do not retrain or choose a run after scoring. Report each run and all outer folds. Use 4,000 deterministic Exp(1) endpoint multiplier draws (seed 20261020); pair weight is the product of its two endpoint weights, retaining every run. Report the 2.5/97.5 percentiles as a conditional endpoint-weighted stability interval for the fixed out-of-fold predictions. It is not an unconditional confidence interval for the entire model-development process or proof of independent biological replication. The projected-loss range reweights the already-fixed P_Q loss contributions; name it fixed-projection conditional sensitivity, not weighted refitting or reprojection. Also report leave-one-compound-out evaluation of the already frozen predictions. No optional post-hoc subgroup defines success.

PREDECLARED DECISION
Strong support for this confirmation requires: principal full-program gain at least 2%; the conditional endpoint-weighted lower stability bound above zero; full gain relative to scalar saturation above zero; positive partner-specific gain relative to the endpoint control; and full-program improvement over the endpoint control in at least two of three run-target evaluations. The 2% threshold is a practical project criterion anchored to the preceding 2.267% development effect, not a journal acceptance standard. Numerical query invariance must pass at 1e-10. If improvement is directional but these criteria are not met, report partial/inconclusive confirmation. If the candidate worsens the principal target, the added capability is not confirmed in this source. Do not rescue a negative primary result with a secondary endpoint or a newly tuned model.

AUDIT AND EXECUTION
Freeze protocol, program mapping, sample membership, outer and inner folds, and all executing source hashes before the first expression-processing call. Record an expression-access start timestamp. Export every candidate and control prediction plus hash before computing held-out losses. Verify non-leakage by poisoning outer-held-out condition means and confirming unchanged fits, inner selections and predictions. Verify singleton, chunk, reorder, duplication and endpoint-swap invariance. Preserve all result rows, chosen hyperparameters and any failure. Run a bounded first timing check; inspect progress after ten minutes and cap an initial cost probe at one hour. Scientific rules cannot be changed after scores. Any unavoidable implementation repair must be documented with before/after hashes and the exact reason, and must not change the scientific selection target.
