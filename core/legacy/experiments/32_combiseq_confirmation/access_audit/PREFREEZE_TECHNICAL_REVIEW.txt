The composition is legitimate. endpoint_raw(q) is in the endpoint incidence feature span. Training correction kernel is P_T K_TT P_T, and query cross-kernel ends in P_T. This should be checked numerically at fit-time using model-defined endpoint coefficients; such a check needs no heldout labels.

Statistical interpretation to retain
The pooled three-run training predictor evaluated on each original run is not a leave-run-out experiment: training uses other pairs from those same runs. The protocol already treats run-target consistency descriptively.
Endpoint multiplier ranges condition on frozen OOF predictions and source data; they do not capture training/development uncertainty. Current P multiplier calculation reweights squared components of the already projected error and does not recompute a weighted projection. Label it fixed-projection conditional sensitivity if retained. This does not affect the principal full-SSE multiplier calculation.
