# WitnessCell 最近九轮实验复现增量（2026-10-31）

本包归档从 NM/NCS 桥接实验到目标补测外层验证的九轮历史实验，并提供统一恢复、核验和复算入口。它用于保留完整证据及复现原成绩；本次打包没有增加实验、调参、改换目标或更新科学结论。

新增压缩包经发布检查必须小于 **10,000,000 字节**（按十进制计）；压缩数据本体为 9,627,404 字节。这一上限对应九轮新增材料；并入既有代码总包后的完整包另计。

## 一条命令复现

在解压后的本包根目录运行（可先运行 `python verify_package.py` 校验交付文件）：

```bash
python reproduce.py --out /abs/fresh_dir
```

`/abs/fresh_dir` 应替换为尚不存在的新绝对路径。程序在新目录恢复原文件、重建可再生缓存、核验哈希，再执行各轮原有复现/评分入口及独立检查。原归档不会被原地覆盖。运行不需要另行下载实验输入；Python 运行环境与依赖需预先安装。

应使用本次核验环境：

| 项目 | 固定版本或设置 |
|---|---|
| Python | 3.12.14 |
| NumPy | 2.3.5 |
| SciPy | 1.17.0 |
| zlib | 1.3.2（Python 所链接的压缩库） |
| pandas / matplotlib | 原桥接 requirements.txt：2.2.3 / 3.10.8 |
| BLAS 线程 | `OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1`、`MKL_NUM_THREADS=1` |

统一入口固定单线程。不同 NumPy、SciPy、BLAS 或压缩库环境可能改变浮点计算或 NPZ 压缩字节；字节一致必须以完整 SHA-256 检查为准，不能用“数值接近”替代。zlib 不是普通 pip 包，其版本由 Python 构建环境决定。

## 如何压缩，以及“精准复现”具体指什么

压缩本体对重复文件内容按字节去重，对适用的数值载荷使用可逆字节 shuffle 后再压缩。恢复会还原原始数据类型、形状、数组顺序和文件内容；没有降低浮点精度，也没有舍弃失败条件或只保存较好结果。

另有 **3,233 个原缓存文件**不直接存储其展开载荷，而由保留的原输入、冻结参数和原科学代码确定性重建：

| 缓存类别 | 文件数 | 重建范围 |
|---|---:|---|
| 新 K562 桥接 | 2,880 | 2,160 个内层 G 矩阵、675 个内层 OOF 预测、45 个最终预测 NPZ。其余 45 个 OOF 参考文件直接保留。 |
| 原合成生成器缓存 | 289 | 因果桥接及隐藏机制桥接中的可再生合成数据。 |
| 历史 Jurkat 缓存 | 64 | 48 个内层 G 矩阵和 16 个 OOF 预测 NPZ。 |
| 合计 | **3,233** | 恢复后与原始记录逐文件核对。 |

恢复完成后，对归档中的 **6,838 条原文件记录**逐项检查 SHA-256。相同内容可对应不同原路径，因此文件记录数不等于去重后的对象数。原科学源码、历史锁文件、参数、预测和评分都以原始哈希为准；缓存重新计算的结果也必须通过原 SHA，才算恢复成功。

这里需要区分三个层次：

1. **原文件精确恢复**：从压缩载荷和可再生缓存恢复文件，逐项匹配原 SHA-256。这是文件级、字节级检查。
2. **冻结结果复算**：用原权重或固定局部计算重放预测，再用原评分器或独立计算核对结果。数值输出逐项比较；绝对工作路径和运行耗时等环境元数据另行说明。
3. **从头重做全部原训练**：重新生成所有设计、训练全部模型、内层选参并评分。统一入口包含必要缓存的原算法重建，以及原烟测、准入和局部流程的复算；**没有把九轮所有训练从头完整重做一遍**。它不应被表述为“九轮全训练均已重跑”。各原包保留的 `REPRODUCE` 文档及训练入口用于更广范围的从头重做。

## 阅读成绩时请先看这一处

第 08 轮与第 09 轮属于不同评价阶段。下列数字均为 `calibrated` 相对 `uniform_expected`（在候选补测中均匀随机选择的期望误差）的改善率，正值表示误差降低，负值表示误差增加：

| 阶段 | 伙伴预测改善 | 目标 AB 预测改善 | 对应记录 |
|---|---:|---:|---|
| 第 08 轮：训练侧六任务校准 | **+4.68324%** | +22.52110% | `scores/calibration/summary.json` |
| 第 09 轮：六目标外层验证 | **−2.4196%** | **−46.9129%** | `scores/outer/summary.json` |

4.68324% 是原训练侧实测收益，不能抹去，也不能写成外层验证收益。第 09 轮没有复现这一收益。第 08 轮原先设定的 5% 准入门仍保留为未通过；后续是在独立保存的继续执行授权下完成外层验证，并未倒改原门槛或原判定。

第 09 轮包中保留了第 08 轮旧报告，其中“外层烟测未运行”描述的是旧报告写作时的状态。当前外层是否执行及其成绩应以第 09 轮 `gate/OUTER_EXECUTED.json`、`scores/outer/summary.json` 和独立审计为准。保留旧报告是为了追溯过程，不代表最新状态仍停留在第 08 轮。

## 已知的原始材料边界

历史 Jurkat 源包的冻结记录引用 `protocol/v1_before_availability_amendment.zip`，但所收到的该源包没有包含这一个更早的协议 ZIP。这是上游归档已有的缺项，本次没有补造或篡改其哈希。Jurkat 缓存恢复核验实际保留的冻结源码、PLAN 与输入，再调用原 `run_smoke.run_budget('high')`；64 个重建 NPZ 与原始缓存逐字节相同。不能据此声称那个缺失的历史协议 ZIP 已被恢复。

本包的 6,838 条原文件记录覆盖本次收到并归档的文件；它不承诺补齐原包本来就没有交付的、更早一层引用文件。

本次交付保持历史阴性结果、失败的准入记录、未被选中的诊断输出和继续执行授权。这里归档的是既有证据，不是一次新的科学实验，也没有把复现通过等同于原科学假说获得支持。
