# WitnessCell精简复现总包 v25

本版对应论文v22，以小于100,000,000字节为发行上限。大容量历史恢复仓、重复预测与包装版本链已移除；论文需要的逐组合统计量、充分统计量、必要条件均值和现行模型源码保留。既有精简实验25–32的461个文件逐字节保持不变。

## 一条命令复现

参考环境Python3.12.14；依赖版本见requirements-reproduction.txt。使用已有兼容环境，无需GPU。所有默认任务均离线运行。

```bash
python tools/verify.py
python tools/reproduce.py --out /tmp/witnesscell_v25_replay
```

输出目录必须新建且位于包外。单任务默认限时300秒。可用任务名见REPRODUCTION_INDEX.json；例如：

```bash
python tools/reproduce.py --task calibration --out /tmp/witnesscell_v25_calibration
python tools/reproduce.py --task sf12 --out /tmp/witnesscell_v25_sf12
python tools/reproduce.py --task growth --out /tmp/witnesscell_v25_growth
```

## 哪些文件没有动

experiments/25_*至experiments/32_*均来自v24原包。没有改动其模型、参数、划分、输入、结果或历史协议。为保持实验25原有全流程重建，仍保留E15的固定GO先验、E19的模型源码/参数和E23的Wessels条件级中间数据；这些旧路径是运行依赖，不是残留的旧发行包。

## 清理与校验

- 删除旧发行导航快照、重复构建/恢复工具和整个447.71MB历史对象仓。
- 旧大矩阵转换为不降精度的逐条件中间量，并执行原数组到中间量的独立核对。
- 未被论文v22使用的早期探索资产不再嵌入；必要模型源码、冻结协议和负结果保留。
- provenance/只保留当前输入来源、受保护实验和清理去向，不复制旧版归档链。
- qa/保存本次等价核验；PACKAGE_MANIFEST.json记录当前逐文件SHA-256。

本版是存储和复现组织升级，没有重新调参或修改论文成绩。代码发行号25.0.0与论文v22、历史预测器v14是不同身份。
