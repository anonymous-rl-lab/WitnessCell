所有后续已精简实验25–32均未改动。它们内部必要的历史实验身份、冻结协议和输入哈希保留；本次清理针对总包的冗余数据及发行版本链，不改写研究发展史。

对旧高维数据的压缩并非截掉读出、降低浮点精度或只保存最后一行结论。核心与风险模块保留逐条件/逐查询可重算统计量，并附原数组到中间量的等价核验。统计量以外的新指标需要原完整数组，不能据本包推定这些信息仍然可恢复。
