# WitnessCell 精准复现代码总包 v26

本版以 `grn_repo_v25.zip` 为基包，加入2026-10-31最近九轮桥接与补测实验，论文身份仍为v22。新增实验位于 `experiments/33_recent_bridge_and_acquisition_20261031/`。本次是归档、存储与复现入口整合，不改变科学模型、数据划分、选样规则或历史成绩。

**10MB限制适用于新增九轮的独立增量包。代码总包保留v25既有内容，不宣称总包小于10MB或100MB。** 最终发行尺寸与校验结果见 `RELEASE_STATUS.json` 及交付说明。

## 运行入口

参考环境Python 3.12.14；依赖见 `requirements-reproduction.txt`。默认离线使用已有环境，无需GPU。

```bash
python tools/verify.py
python tools/reproduce.py --task recent_bridge --out /tmp/witnesscell_v26_recent_replay
```

输出目录必须新建且位于代码包外。新增任务默认限时900秒；旧12个任务的定义保持不变，默认仍各限时300秒。运行全部任务会包含旧12个任务和本次新增任务：

```bash
python tools/reproduce.py --out /tmp/witnesscell_v26_all_replay
```

本次打包不会把v25既有“12/12通过”冒充本轮重新运行结果。旧任务的历史证据继续保留；本次实际执行项目与结果以新QA记录为准。
