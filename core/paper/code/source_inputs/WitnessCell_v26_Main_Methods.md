# WitnessCell predicts combinatorial perturbation responses through endpoint and partner learning

## Abstract

Predicting unmeasured combinations requires learning the response components supported by joint interventions. WitnessCell separates endpoint refinement from partner-dependent correction and links each construction to an experimentally testable capability. An exact response-space identity identifies a limitation of endpoint residual transfer, motivating explicit partner learners. Controlled causal analysis shows how joint measurements resolve target ambiguities under a declared mechanism family. The released predictor ranks first among sixteen eligible benchmark entries across four datasets, including the 540 double-perturbation records. A procedure frozen before Jurkat fitting reduces growth-response error by 6.43% across 617 held-out combinations, with a 6.18% partner-error reduction. In a developmental RNA panel, measurement-informed shrinkage retains concentrated useful corrections while suppressing adverse increments. WitnessCell provides combination predictions and component-specific tests that connect partial perturbation screens to transcriptional and functional responses.

Combinatorial perturbation screens measure how cellular responses change when interventions act together. Their growing scale creates an opportunity to predict combinations beyond those measured, a central capability sought in virtual cells.[1,2] Transcriptomic profiles describe broad response changes, whereas growth phenotypes provide a functional endpoint.[3,4] Researchers with single-perturbation measurements and a partial combination screen need predictions that exploit those observations and an account of what additional response structure the model has learned. The useful output is a predicted response for a specified unmeasured combination, supported by evaluation at the same biological readout.

Existing methods compose latent intervention representations, incorporate biological graphs or use models pretrained on large expression collections.[5,6,7,8,9] Benchmarks and strong linear references have sharpened the assessment of their predictive value.[10,11] Systema further shows how systematic variation can obscure perturbation-specific prediction.[12] A related question arises within combination prediction: joint measurements can refine effects associated with individual perturbation endpoints or reveal changes that depend on exchanging partners. Both can improve complete-response error. Separating these capabilities requires a response contrast and a model construction matched to that contrast.

The experimental information is equally specific to the target. Mechanisms can agree on permitted single interventions while disagreeing on an unmeasured double intervention. An informative joint measurement can distinguish those explanations within a declared mechanism family. Thus a target response can become identifiable before an entire regulatory network is recovered. This perspective asks which combinations carry information about the requested response, complementing questions about sample size and estimation accuracy.

WitnessCell turns these distinctions into a prediction method. Its released core combines measured or inferred single responses, nonlinear composition and residual transfer from observed combinations. An endpoint is an intervention identity whose contribution spans the response readouts; it is not restricted to the targeted gene's own RNA coordinate. Classical projection tools isolate response contrasts that cancel arbitrary additive endpoint contributions.[13,14] The released endpoint residual cannot alter these contrasts. Explicit partner extensions address that capacity through a response-similarity kernel for RNA and a residual matrix for functional measurements. Training measurements determine the fitted correction and, for the RNA implementation, its readout-specific amplitude.

The study links experimental information, model capacity and measured utility. Controlled causal analysis establishes the information principle; a four-dataset comparison tests the released predictor; a procedure-frozen Jurkat evaluation tests functional partner prediction. RNA development analyses examine correction benefits and their concentration, while other-source evaluations delimit transfer. A complete functional-screen workflow and two further research uses connect the predictions to experimental practice. Each implementation retains its own fitting parameters and evidence status. The contribution is a usable combination predictor whose learned endpoint and partner capabilities can be evaluated separately.

## Results

### WitnessCell separates endpoint refinement from partner-dependent prediction

WitnessCell takes control measurements, permitted single interventions, a training set of joint interventions and the identities of requested combinations. The response can be a vector of transcript abundances or a measured functional phenotype. Experimental support comprises the available intervention identities, their pattern of overlap and the measurements associated with them. The workflow first constructs a baseline response, then estimates a correction from the measured combinations. Model selection uses permitted training or validation observations, and evaluation excludes the complete identity of each query combination (Fig. 1a).

For transcriptomic prediction, a measured single effect is its condition mean relative to control. When an endpoint lacks a measured single, the released core combines the mean response of training singles, Gene Ontology neighbours and an on-target response anchor. A training-only amplitude extension refines the target coordinate when nested endpoint holdouts support the change. These ingredients allow the same core to address combinations with different levels of endpoint exposure. They also make the source of information explicit: a measured single supplies an observed effect, whereas an unmeasured endpoint uses a prediction from permitted response and annotation information.

The two single effects are combined through a coordinatewise saturation rule. A regularized endpoint-sharing kernel then transfers residuals from training combinations to the query. The final predictor therefore incorporates both the single-perturbation response and information learned from joint measurements. Its nonlinear composition and residual strength are selected using the declared validation procedure. This released configuration supplies the formal benchmark results below. The subsequent partner and functional implementations have their own fitted components and are evaluated as extensions of the response construction.

To determine which capability a correction adds, consider the unsigned endpoint-incidence matrix $X_Q$ for a collection of query pairs. Each row identifies the two interventions present in that pair. The projector

$$P_Q=I-X_QX_Q^{+}$$

removes responses expressible as arbitrary sums of endpoint contributions. For a four-pair rectangle, the corresponding contrast is $Y_{AB}-Y_{AD}-Y_{CB}+Y_{CD}$. It measures whether exchanging the same partners has different consequences in two backgrounds. This is a population-response comparison; the observations can come from different cells. Shared nonlinear composition can also generate such a contrast, so its interpretation is partner-sensitive response variation rather than a uniquely identified molecular interaction.

The released endpoint residual has the form $\delta_Q=X_Q\Theta$. Consequently, $P_Q\delta_Q=0$: this branch can improve complete responses but cannot add a new endpoint-eliminated contrast. The nonlinear baseline itself can contain partner-sensitive variation. This algebraic distinction motivates an explicit extension,

$$\widehat Y_{qj}=F_{qj}+w_jG_{qj},$$

where $F$ is the baseline refitted for the corresponding implementation, $G$ can change partner contrasts and $w_j$ controls the RNA contribution for readout $j$. The RNA implementation uses a kernel built from single-response similarities; the growth implementation uses a symmetric residual matrix. Their usefulness is determined by held-out error relative to their own refitted baselines (Fig. 1b,c).

Configuration choice follows the user's inputs and objective before query outcomes are examined. Normalized RNA summaries and training/validation combinations support the released core, including its missing-single head. Measured endpoint responses, training sampling halves and an estimable partner design support the RNA R extension. Repeat-specific functional measurements use the growth residual model. A fixed transcriptional objective and mode-aware response predictions support PairPick. These are declared analysis paths, not a selector optimized on test performance. The new-input interfaces execute the unchanged released core or the frozen functional procedure, returning responses, baselines and fitted settings. Supplementary Tables S29 and S30 specify configuration requirements and evidence status.

### Joint interventions resolve target ambiguities left by single perturbations

For measured interventions $\mathcal E$, let $\mathcal M(\mathcal E)$ contain mechanisms in a declared class that produce the same population observations. The compatible answers to query $q$ are

$$\mathcal T_q(\mathcal E)=\{\mu_m(q):m\in\mathcal M(\mathcal E)\}.$$

The query is identified when these answers coincide. An informative intervention separates mechanisms whose disagreement affects that query. This target-centred definition connects causal discrimination to a specific response rather than requiring every internal parameter to be determined.

A controlled system has a binary source $X$, six mediators $A$ to $F$ and a downstream response with affine mediator effects plus a hidden direct or gated contribution. Candidate gates include $h_A=A\lor(B\land C)$. Under control and every permitted single mediator knockout, this gate equals the source. A direct-source effect and a gated effect can therefore agree on those observations. Joint knockout of $A$ and $B$ makes the gate zero while the source can remain active, exposing the distinction (Fig. 2a).

Two panels add four joint interventions to control and seven singles: the informative panel uses $AB,BC,DE,DF$, and the comparison panel uses $AD,BD,BE,CF$. They match every endpoint degree, the number of conditions and the observation budget. Each condition contains 256 observations, giving 3,072 per panel. The four query pairs $AC,AF,CE,EF$ are absent from both panels; their target is $\Delta=\mu_{AC}-\mu_{AF}-\mu_{CE}+\mu_{EF}$ (Fig. 2b).

Four generating worlds have identical training distributions in the comparison panel but targets $0,-0.5,0,-0.5$. Any estimator based on that panel has equal-world squared-error risk $\mathbb E[(T+0.25)^2]+1/16\geq0.0625$ (Fig. 2c). Repeating those conditions more precisely preserves the ambiguity. The informative panel exposes the relevant gate directions. Across 1,000 paired noise seeds, the same candidate least-squares procedure reduces target MSE from 0.065295 to 0.004674, a 92.84% reduction; the paired difference is −0.060620, with 95% Monte Carlo interval [−0.061103, −0.060137] (Fig. 2d).

Contrast GLS achieves MSE 0.005247 on the informative panel, with an unresolved difference from candidate least squares. The risk reduction therefore demonstrates the value of information layout, not an estimator-exclusive advantage. Allowing arbitrary simultaneous gate contributions introduces a function that vanishes on the informative training panel while changing the query. Identification is lost in that enlarged family (Supplementary Note 2).

These results isolate a principle relevant to combination prediction: equal observation counts and endpoint coverage can supply different information about the same unmeasured target. Biological analyses below evaluate how existing combination measurements improve a fitted predictor; they do not infer the synthetic mechanism family in real cells.

### The released predictor leads both the formal track and its double-perturbation subset

Predictive utility was evaluated in the released genetic-combination track of scPerturBench.[10] The comparison retained Norman, Wessels, Schmidt and Replogle_exp6, three public split seeds and the specified six-metric aggregation on the top 100 perturbation-affected genes.[3,15,16,17] Fifteen eligible comparator entries, including simple references, and WitnessCell contributed sixteen entries. The formal population comprises 654 operation–seed records: 540 double perturbations and 114 unseen singles. We preserved that ranking and decomposed the same saved operation scores by prediction target, without retraining or changing the aggregation rule.

WitnessCell ranked first in the full track, with mean operation rank 3.803, followed by Scouter at 5.411 and the released linear model at 5.725. In the double-only subset, WitnessCell retained first place with mean rank 3.515, followed by Scouter at 5.150; the linear model and GEARS had mean ranks 6.180 and 7.754 (Fig. 3a). Clustering repeated seed records by dataset and pair identity gave a WitnessCell–Scouter difference of −1.635, with a 95% bootstrap interval of −2.117 to −1.141. Corresponding differences were −2.665 against the linear model and −4.239 against GEARS, with intervals of −3.002 to −2.317 and −4.764 to −3.702 (Fig. 3c). All fifteen double-only comparator differences had pointwise 95% cluster-bootstrap intervals below zero. These intervals describe the fixed scoring archive and are not simultaneous, multiplicity-adjusted confidence statements (Supplementary Fig. S2).

Endpoint exposure provided a further decomposition. WitnessCell ranked first by point estimate in each double-perturbation subgroup: neither endpoint seen, one seen and both seen, containing 43, 374 and 123 records, respectively (Fig. 3b). The subgroups share some underlying pair identities across split seeds and are not independent confirmations. In the 114 unseen-single records, WitnessCell ranked second at 5.167 behind the linear model at 3.570. The overall combination result therefore coexists with a distinct ordering for single-response generalization. Full sixteen-method tables, all reference contrasts and dataset-specific raw-loss estimates are provided in Supplementary Tables S25–S26 and their machine-readable sources.

Dataset and metric decompositions delimit the aggregate advantage. WitnessCell ranked first in Norman, Wessels and Replogle_exp6 and fourth in Schmidt. Relative to Scouter, mean native-scale double-perturbation MSE decreased by 11.87% and 44.80% in Norman and Replogle_exp6, but increased by 19.34% and 29.02% in Wessels and Schmidt (Fig. 3d). Mean raw losses and aggregated operation ranks measure different aspects of performance. Across the full track, WitnessCell led the correlation, MSE, energy-distance and symmetric-KL rankings, while ranking ninth for Wasserstein and eighth for common differential expression. The mean-based distribution adapter is shared evaluation machinery; it does not by itself explain this asymmetry or establish full cell-distribution prediction.

A separate weighted-error analysis of 540 combinations gave a 24.87% reduction against the archived training-mean additive reference, with loss ratio 0.7513 and pair-bootstrap interval 0.7031–0.8019. This comparison uses its named reference once. The official `linearModel` and `trainMean` scoring rows are distinct: 529 of their 540 double-perturbation MSEs differ. An implementation-level equivalence does not establish equality of historical scoring inputs; the provenance distinction is documented in Supplementary Table S31. The formal ranking retains both original rows unchanged.

These gains combine several useful operations. The single-response head estimates unavailable endpoints; nonlinear composition accounts for response saturation; and measured combinations refine shared endpoint contributions. After removing manipulated target coordinates, complete non-target MSE ratios against the shared-endpoint additive reference were 0.9049 in Norman and 0.6459 in Wessels, corresponding to reductions of 9.51% and 35.41%. An independently selected saturation comparator still left a 32.36% MSE reduction in Wessels. The advantage therefore extends to downstream readouts rather than being confined to the directly targeted genes.

In Wessels, increasing the retained residual library from one quarter to one half and all available training combinations increased MSE gain over the paired nonlinear backbone from 19.10% to 27.42% and 33.25%; weighted gains were 26.81%, 33.91% and 37.66% (Supplementary Fig. S3). The full-minus-quarter MSE gain was 14.15 percentage points, with a paired interval of 12.42–16.06. This comparison holds the backbone fixed and measures the return from additional combination support.

Structural attribution identifies what this residual transfer adds. The twelve released query graphs supplied 212 algebraic contrast dimensions. Comparing the final prediction with its own jointly selected nonlinear backbone changed projected-error ratios by at most $6.34\times10^{-8}$, within saved-array precision. The residual branch therefore behaved as its endpoint-space algebra predicts. Its strong complete-response performance supplies a practical baseline and motivates a precise next question: can a correction acting outside that space improve partner-sensitive responses on held-out combinations?

### A frozen functional procedure predicts partner-dependent growth responses

Functional growth provides a direct test of whether explicit partner structure improves an experimentally meaningful response. The partial-screen completion task used repeat-specific measurements from the Horlbeck genetic-interaction study.[4] Each repeat had a baseline fitted from permitted single and double measurements. A symmetric matrix then modelled the mean residual shared across repeats. A signed rank-one matrix was the primary correction; a spectral-shrinkage matrix provided a more flexible secondary implementation.[18] Selection used training combinations, and both corrections were evaluated against the baseline refitted for the same observations.

For eighty K562 genes, low and high training budgets contained 421–422 and 2,317–2,318 pairs per fold. The 632 evaluated pairs stayed fixed across the three folds. Increasing support raised the rank-one correction's complete-response gain from 0.27% to 11.03%, while its partner gain rose from −0.033% to 11.68%. The high-budget spectral correction gave complete and partner gains of 11.39% and 10.67%. The baseline itself improved by 10.12% when supplied with additional observations. The data therefore supported separate benefits for the baseline and for the added partner structure (Fig. 4a,b).

These budgets change condition count, endpoint degree and layout coverage together. Their value lies in demonstrating that more extensive combination measurements can support a transferable residual prediction on fixed queries. The controlled mechanism experiment isolates layout information at equal budget; the growth experiment tests the return from expanding real experimental support. Considering both avoids attributing every biological data-volume effect to a single structural property of the design.

The procedure was frozen before evaluation in Jurkat, using 79 genes, 2,464 training pairs and 617 held-out pairs. Model coefficients were estimated from Jurkat training data. This tests portability of the procedure to another cellular environment within the same study. The primary rank-one correction reduced pooled growth-response error by 6.43% and endpoint-eliminated partner error by 6.18%. Complete gains were 4.45% and 8.88% in the two measured repeats. The spectral correction achieved gains of 8.16% and 5.90%, respectively (Fig. 4c,d). Removing each endpoint from scoring left complete rank-one gains between 4.95% and 7.10%.

Illustrative pairs show the practical meaning of the correction. For TTI2–PGK1, the mean baseline prediction was −0.274 against an observed response of −0.321; the correction moved it to −0.287. For TTI2–OGFOD1, the baseline was −0.069 against −0.036, and the correction moved it to −0.058. The shared TTI2 endpoint receives corrections in opposite directions depending on its partner (Fig. 4e). These descriptively selected examples explain a prediction already evaluated across all pairs; they do not establish the molecular mechanism behind the response.

For a user of a partial growth screen, the computational workflow is: provide measured singles and combinations, fit the baseline and residual matrix, and obtain functional predictions for remaining pairs. A new-input adapter accepts gene identities, two-repeat single responses, observed pair responses and query identities without query outcomes. It refits the archived baseline and residual procedure and exports complete predictions and increments. The supplied real-data example uses the existing 2,464 Jurkat training pairs and 617 query identities; its execution verifies software access, rather than adding an independent evaluation. The original held-out measurements assess predictive utility. This application gives the common response construction a functional interpretation independent of any RNA-based recommendation. It shows that a modest structured correction, when supported by sufficient measured combinations, can improve an experimentally meaningful phenotype.

The signed low-rank structure permits buffering and aggravating corrections through a shared statistical representation. Its interpretation is a pattern of functional residuals across partners, with the global evaluation establishing whether that pattern generalizes. The same fitted correction is shared across repeats by construction; its gains are assessed against both sets of measured outcomes, and the second cell environment tests the portability of the fitting procedure. These different comparisons connect a compact computational construction to a useful functional outcome without requiring the matrix factors to be assigned a molecular identity.

### RNA analyses explain selective partner gains and their scope

The RNA partner extension was evaluated on a matched CaRPool panel from the Wessels study.[15] Fourteen measured singles and 55 unordered combinations were assigned to five outer folds. All cells and repeated measurements of a combination followed its assignment. Eleven rectangles whose four predictions came from the same fitted model provided the primary contrast evaluation over 4,995 non-target readouts. The baseline $M_0$ included saturation and endpoint refinement and was refitted inside each permitted training subset. This panel informed development, so the evaluation tests held-out combinations within the development setting.

The additional component transfers residuals using symmetric products of single-response similarities. Training projection removes the freely fitted endpoint effects, and the query operator removes their corresponding continuation. The resulting kernel can change partner contrasts that the endpoint-sharing residual cannot. Its unit-weight prediction is $M_1=M_0+G$. This construction uses response similarity to share information across combinations, while evaluating the added component against a baseline already benefiting from combination measurements.

Repeated training measurements control the amplitude delivered to each transcript. After splitting permitted cells into disjoint halves and projecting away endpoint effects, the correction for readout $j$ is multiplied by the clipped cross-half agreement divided by average half energy. A readout with little projected cross-half agreement receives a small correction. This rule changes predictions before scoring and uses no query response. The halves measure within-experiment sampling agreement and can share guide or preparation effects; their role is to adjust the correction rather than supply independent biological replication.

The unweighted partner extension reduced held-out rectangle error by 9.44% relative to $M_0$. Adding measurement-derived shrinkage, denoted $R$, increased the reduction to 15.96%, with complete-response error reduced by 9.28% (Fig. 5a,b). The shrinkage predictor improved contrast error in nine of eleven rectangles against $M_0$ (Fig. 5c) and in all eleven against both the unit-weight extension and a training-selected uniform shrinkage control. Relative to the latter control's error, the reduction was 6.94%. All five outer folds had positive aggregate gains, including one close to zero.

Matched GEARS and Scouter runs used the same outer combination identities and evaluation mask, each with three optimization seeds.[6,7] The $R$ extension reduced rectangle error by 10.81% against the GEARS seed-mean error and by 12.88% against Scouter. These comparisons aggregate seed-specific losses, whereas the later PairPick application averages prediction vectors before scoring. Inner-selection budgets also differed between the recorded RNA workflows. Optimization seeds characterize fitting variation on this shared outer task.

Readout contributions identify where the RNA benefit arises. Ten readouts accounted for 92.13% of the positive error reductions produced by $R$, while negative contributions remained in the primary loss. Under training-variance-standardized scoring, its gain was −0.118%; after removing the previously locked ten-readout set, the gain was −0.380% (Fig. 5e,f). The extension therefore captures useful raw-scale partner variation concentrated in a small response subset. The annotated readouts do not constitute independently validated biological programs or an estimated number of independent programs.

A signed error budget explains the shrinkage benefit more directly (Fig. 5d). For each readout, we summed the reduction in squared error over all eleven rectangles, then separated positive reductions from adverse increments. Relative to the same total $M_0$ error, $M_1$ contributed 20.83% positive reduction and 11.39% adverse increment, giving 9.44% net improvement. For R these quantities were 17.64%, 1.68% and 15.96%. Thus R retained 84.71% of the positive reduction while reducing adverse increments by 85.25%. The calculation describes the same development panel; it shows how selective attenuation improves the net prediction rather than supplying an independent replication.

Outside the fixed ten-readout set, the adverse gain changed from −10.03% for $M_1$ to −0.38% for R. This connects the method's amplitude control to reduced damage in weakly supported readouts while preserving its strongest response changes. The fixed set includes S100A9, S100A8, S100A12 and LYZ; the archived four-corner responses show the changes being corrected without defining a newly validated biological program. Uniform shrinkage, 200 expression/variance-stratified weight permutations and matched-norm random increments remain complementary controls (Supplementary Notes 6 and 13).

Independent-source checks further separated baseline accuracy from partner transfer. In a Dixit RNA evaluation, the complete baseline improved over additivity by 23.43%, while the extra correction gave a 0.270% complete-response improvement and a −0.033% partner gain.[19] A frozen Combi-seq drug-program evaluation also lacked an additional partner improvement.[20] Together with the positive matched-panel result, these findings identify a concrete capability and its present range: explicit partner structure can improve prediction, but its transfer depends on the readout, measurement support and experimental context.

### Functional-screen completion and further research uses

The primary biological use is to extend a partially measured functional screen with predictions for remaining combinations. Complete-response accuracy evaluates that delivered output; endpoint-eliminated accuracy tests the added partner capability. The user selects a configuration from the assay and available measurements before examining query outcomes. The accompanying interfaces expose fitting settings and component predictions, allowing these two questions to be checked on subsequent measurements.

Two separate retrospective analyses examine further uses (Supplementary Fig. S1). Risk selection retained approximately half the evaluation weight with accepted/all-query MSE ratio 0.5343 on 213 records from 33 calibration-disjoint pair identities. PairPick, using R-G, selected the empirical best in 19 of 28 fixed-anchor tasks, with mean regret 0.006197. Its achieved utility tied linear prediction in 27 tasks, and its choices matched PRESAGE in all 28. The original design table directly matched 15 of 49 detected gene-mode labels, with one enhancer-only correspondence and 33 unlisted pairs.[21] These results illustrate an executable recommendation operation and its limits: response differences often leave choices unchanged, and detected-label evaluation does not confirm intended cell-level constructs. Full outcomes, candidate sizes and identity status are retained in Supplementary Tables S17–S19, S28 and S33.

## Discussion

WitnessCell connects a usable combination predictor to an explicit account of the response capability learned from joint measurements. The released core supplies broad predictive performance, including a lead in the double-perturbation benchmark. The response-space identity shows exactly what its endpoint residual can change and motivates a correction with additional partner capacity. Matched-baseline evaluation then determines whether that capacity improves unmeasured responses. This construction links the scientific question to an estimator and a falsifiable performance test.

The causal analysis explains why the available measurements matter for a requested response. Some joint layouts distinguish mechanisms that singles and alternative equal-budget layouts leave ambiguous. The result is conditional on a specified mechanism family, and strong estimators can exploit the same informative panel. It contributes a target-specific information principle, while the biological comparisons establish empirical prediction capabilities. Neither the projection identity nor the synthetic information result establishes recovery of a complete biological regulatory network.

Functional growth supplies the clearest procedure-transfer evidence for an explicit partner increment. More extensive K562 combination support permits a structured residual model to improve held-out phenotypes; after freezing the procedure, refitting on Jurkat training observations retains complete and partner gains. This is transfer across cellular contexts within one study. Rank one remains primary, with the more flexible spectral result reported separately. These outcomes support completion of partial functional screens, rather than a claim that low-rank completion itself is new or universally optimal.

The RNA analysis identifies how amplitude control can earn its complexity. Training-half weights preserve most of the positive readout-level reduction while strongly reducing adverse increments. The benefits are concentrated, and independent-source RNA/program evaluations do not establish broad partner transfer. Within-experiment halves can also preserve shared experimental effects. Consequently, the weights describe measurement agreement useful for prediction, rather than independently calibrated biological reliability. The functional implementation has a different readout and regularization rule; its positive result does not validate the RNA weighting mechanism.

The evidence supports a practical distinction between representational capacity and successful learning. Complete-response accuracy, partner-sensitive accuracy and decision utility answer different questions. The benchmark's native-scale losses vary by dataset and comparator, and many recommendation tasks give the same choice to different predictors. Reporting those outcomes alongside aggregate gains makes the method's useful range assessable. Supplementary Table S30 records development exposure, the object and timing of freezing, and source relationships; positive and negative evaluations retain their original status.

For experimental users, the immediate opportunity is prediction of additional transcriptional or functional combinations from existing measurements, using an implementation matched to the assay. The software returns the response and its baseline, while the functional interface also exposes the selected residual increment. Future work can examine broader readouts, independent repeat structures and acquisition of informative combinations.[22,23] The retained one-measurement acquisition tests did not confirm an outer-target gain, so adaptive experimental design remains a separate direction. The present contribution is a predictive method whose endpoint and partner capabilities can be tested against the responses that researchers seek to measure.

## Methods


### Study design and implementation identities

The study reanalysed public perturbation measurements and used a specified synthetic causal system. No new biological samples were collected. The primary response method is the released WitnessCell transcriptomic core. The matched RNA partner predictor, functional growth model, analytic-risk predictor and empirical risk ranking are separately fitted implementations. WitnessCell–PairPick names the partner-selection application; its default response configuration is the archived R-G algorithm. PairPick-Stable and PairPick-TargetRank retain their separate identities. Naming changes do not alter fitted predictions, losses or archived model identifiers.

Biological prediction splits assign unordered perturbation pairs, keeping associated cells, guides, orientations and repeated measurements together. Permitted singles remain available. Mixed activation/repression tasks additionally group mode variants by physical gene pair. Inner fitting reconstructs preprocessing, baseline and correction from the allowed observations. Development panels, procedure-transfer evaluations and source-transfer comparisons retain their original status. Repeated optimization seeds, overlapping folds, shared-source datasets and algebraic contrast dimensions are not counted as independent biological replications. The archive preserves original failures, subsequent development and local prediction freezes. Supplementary Table S30 distinguishes development exposure, frozen procedures or predictions, and within-study versus between-study evaluation. Local separation of training and scoring is not independent third-party blinding.

### Data sources and response definitions

The released benchmark used scPerturBench-processed Norman, Wessels, Schmidt and Replogle_exp6 datasets, their Gene Ontology support filters and public split seeds 1–3.[10] Primary experimental sources include Norman GSE133344, Wessels GSE213957 and Replogle GSE146194; Schmidt retains the benchmark's processed labels with the primary T-cell study as provenance.[3,15,16,17] Benchmark and matched CaRPool analyses share the Wessels source and constitute different tasks, not independent source replication. The full benchmark contains 540 combination–seed and 114 unseen-single records.

RNA effects are condition means relative to the permitted control reference. Source preprocessing and gene axes are retained for each experiment. The matched CaRPool task has 55 pairs, fourteen singles, five outer folds, eleven same-fit evaluation rectangles and 4,995 non-target readouts. Its neural comparators retain their 5,020-gene model axis and use the same scoring mask. Growth phenotypes are repeat-specific Triple Sequencing measurements from GSE116198.[4] Independent checks use Dixit GSE90063/GSM2396860 and Combi-seq GSE174695.[19,20] The mixed-mode selection application uses GSE220974.[21]

### Single-response estimation and the released transcriptomic core

For a measured single $g$, the effect is $e_g=\mu_g-\mu_0$. Missing endpoints use a head combining the equal-condition mean of training singles, a ten-neighbour Jaccard-weighted Gene Ontology response and a self-response anchor. Leave-one-single feature construction excludes the endpoint being fitted. Coefficients use numerical ridge $10^{-8}$ and clipping to $[0,2]$. The additional on-target amplitude head uses generic self response and sign-matched tail and root-mean-square fingerprint features, relative ridge 0.2 and coefficient bounds $[-1.5,1.5]$.

For every outer training endpoint, nested checks remove that endpoint before fitting the base head and amplitude correction. Activation requires positive one-sided 95% lower bounds for both relative all-gene MSE gain and top-100 correlation gain; top-100 MSE is recorded but is not a third gate. Fewer than six usable endpoints retains the preceding head. Measured endpoints are unchanged. This amplitude extension is excluded from selection of the released combination hyperparameters.

With $e^{\mathrm{base}}$ and $e^{\mathrm{final}}$ denoting the preceding and final endpoint effects, the released predictor is

$$\widehat y_q=\mu_0+S_\alpha(e_g^{\mathrm{final}}+e_h^{\mathrm{final}})+\gamma K^{\mathrm{end}}_{QT}(K^{\mathrm{end}}_{TT}+\eta I)^{-1}R_T,$$

where $S_\alpha(z)=z/(1+\alpha|z|)$ acts coordinatewise, $K^{\mathrm{end}}_{TT}=X_TX_T^\top/2$ and $K^{\mathrm{end}}_{QT}=X_QX_T^\top/2$. Training residuals $R_T$ subtract $\mu_0+S_\alpha(e_g^{\mathrm{base}}+e_h^{\mathrm{base}})$. This conservative-residual/final-backbone convention reproduces the released implementation; endpoint versions coincide when their singles are measured.

Validation selects $\alpha\in\{0,.02,.05,.1,.2,.5\}$ and $\eta\in\{.01,.03,.1,.3,1\}$. For transferred correction $D$ and remaining validation error $E$, the amplitude is $\gamma=\operatorname{clip}_{[0,1]}\langle D,E\rangle/\|D\|_F^2$, with zero for zero correction energy. MSE ties favour smaller $\alpha$, then smaller $\eta$. The original use of validation combinations is retained and distinguished from later extensions selected entirely inside their outer training sets.

### Benchmark aggregation and response losses

The formal comparison reconstructs the released top-100 six-metric aggregation over all four datasets. Fifteen eligible published methods plus WitnessCell form the sixteen-entry track. The primary mean operation rank follows the benchmark's aggregation code; equal-dataset and two-panel aggregations are robustness summaries. Metric-specific ranks remain separate. For distributional metrics, the benchmark uses predicted means with training-control variation, rather than a fitted distribution of perturbed cell states.

The 540-record combination analysis uses the archived training-mean additive reference, which substitutes the equal-condition training-single mean for an unavailable endpoint. This self-contained weighted analysis uses that reference once. It is separate from the official `linearModel` scoring row. The released branch-level correspondence does not demonstrate identical historical score inputs: the archived double-only MSEs differ in 529 of 540 records (maximum absolute difference 0.0235). Both official rows remain unchanged; source and scoring-object distinctions are detailed in Supplementary Note 14. Later shared-endpoint addition, independently selected saturation and the nonlinear backbone selected jointly with the final residual are distinct comparators. Structural attribution compares each final prediction with its own actual backbone.

The historical weighted loss uses one cell half's target-versus-control Welch statistics, followed by absolute value, min–max scaling and squaring, to weight error against the other half. Target coordinates are retained for that endpoint. Non-target controls remove query targets and renormalize weights, use full-cell means and geometrically aggregate seed-wise ratios. Five thousand pair-bootstrap draws carry repeated seed records together. Gains are $1-L_{\mathrm{method}}/L_{\mathrm{reference}}$, using the declared loss and pooling convention. A percentage-point increase between gains is kept distinct from a relative reduction between errors.
