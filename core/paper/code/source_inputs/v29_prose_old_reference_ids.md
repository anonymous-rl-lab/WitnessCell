# WitnessCell predicts combinatorial perturbation responses through endpoint and partner learning

## Abstract

Joint perturbation measurements can improve predictions by refining individual intervention effects or learning how those effects change with a partner. WitnessCell distinguishes these gains and learns partner corrections that its endpoint refinement cannot supply. The released predictor ranks first among sixteen entries in a four-dataset benchmark, including its double-perturbation subset. A functional procedure fixed before Jurkat fitting reduces growth-response error by 6.43% across 617 held-out combinations and partner-contrast error by 6.18%. In a developmental RNA panel, training-measurement agreement reduces harmful corrections while retaining useful changes, with gains concentrated in a small transcript subset. Controlled causal analysis explains how joint measurements distinguish otherwise unresolved responses within a specified mechanism family. WitnessCell provides executable tools to predict unmeasured combinations and test what existing combination measurements add beyond refined individual intervention effects.

Combinatorial perturbation screens measure how a cell's response to one intervention changes when another is added. Predicting unmeasured combinations would extend these screens and help researchers study gene function across cellular contexts.[9,10,11] A practical starting point is a collection of single-perturbation measurements and a partially measured combination screen. The immediate goal is to predict the remaining expression or functional responses. However, a reduction in overall prediction error leaves an important question open: did the model estimate each intervention's contribution more accurately, or did it learn changes that depend on the partner?

Existing methods combine intervention representations, transform cellular states or use gene relationships to predict responses.[12,13,14,15,16] Large-scale benchmarks and strong simple references test whether these predictions improve on alternatives.[21,22] Systema examines whether predictions capture perturbation-specific changes beyond systematic variation, while Miller and colleagues test whether evaluation metrics distinguish informative predictions.[23,24] These questions also matter for combinations. Contributions associated with each intervention can vary across all measured genes and still leave a partner-exchange comparison unchanged. Distinguishing this case from improved partner prediction requires examining both the model's construction and its held-out responses.

WitnessCell addresses this distinction within a prediction method. Its released core combines single responses nonlinearly and learns a correction from measured combinations. We show that this correction refines contributions associated with individual intervention identities, termed endpoints, while leaving a defined set of partner comparisons unchanged. We then construct explicit partner corrections and test them against the same fitted baseline. A controlled causal system provides the accompanying information result: the choice of joint measurements can determine whether mechanisms giving different answers to an unmeasured combination can be distinguished at all.[25]

The released predictor is evaluated across four transcriptomic datasets. A functional extension tests whether partner learning improves unmeasured growth responses, using a procedure fixed before fitting in a second cellular environment. An RNA extension examines how training measurements can restrain harmful corrections. Together, these analyses connect a precise limitation of endpoint refinement to a constructive way of predicting additional partner-dependent responses. The supplied interfaces let researchers fit the transcriptomic core or functional model to existing measurements, predict unmeasured combinations and inspect the contribution of each fitted correction.

## Results

### WitnessCell separates endpoint refinement from partner-dependent prediction

WitnessCell starts from control and available single-perturbation measurements, observed combinations and the identities of requested combinations. For RNA, the released core uses measured single effects when available and estimates missing ones from permitted training responses and gene annotations. It combines the single effects through a saturation rule, then transfers residuals from measured combinations that share endpoints with the query (Fig. 1a). Training or validation measurements determine the fitted settings; the complete identity of each evaluation combination is held out. The resulting predictor can use combination data even when some requested single effects have not been measured.

To identify what the transferred correction learns, consider four combinations: A with B or D, and C with B or D. The contrast

$$\Delta=Y_{AB}-Y_{AD}-Y_{CB}+Y_{CD}$$

asks whether exchanging B for D has the same effect in backgrounds A and C. Any contribution depending only on A, B, C or D cancels. Thus, estimating these individual contributions more accurately can improve complete responses while leaving this contrast unchanged. Here an endpoint contribution spans all measured readouts; it is not restricted to the RNA coordinate of the targeted gene. The contrast compares population responses measured under different conditions, without requiring the same cells to undergo multiple interventions.

This cancellation extends to a collection of query pairs. Let $X_Q$ indicate the two endpoints present in each pair. Classical projection gives $P_Q=I-X_QX_Q^+$, which removes sums of endpoint contributions.[26,27] The released residual branch has the form $\delta_Q=X_Q\Theta$, so

$$P_Q\delta_Q=0.$$

This identity applies to the residual branch. The nonlinear baseline can already produce partner-dependent contrasts. The question is therefore whether an additional correction can improve those contrasts beyond that baseline, rather than whether all partner variation is absent from the core (Fig. 1b,d).

WitnessCell adds such corrections in two separately fitted implementations. The RNA extension transfers information between combinations with similar single-response profiles after removing endpoint contributions. The functional extension fits a symmetric matrix to residual growth responses. Both can change the contrast above. Each is compared with its own baseline, fitted to exactly the same permitted observations, so any improvement measures the contribution of the added learner (Fig. 1c). RNA training measurements further control the correction applied to each transcript.

Users choose a configuration from their measurements and prediction objective before examining query outcomes. Normalized RNA summaries support the released core; measured single responses and training sampling halves support the RNA partner extension; repeated functional measurements support the growth model. The executable core and functional interfaces return predictions, baselines and fitted settings. Supplementary Table S29 specifies the required inputs for each configuration, and Table S30 records how each evaluation was developed and frozen.

### Joint interventions resolve target ambiguities left by single perturbations

Before a model can learn a partner response, its training measurements must distinguish the answers of interest. We examined this requirement in a controlled causal system with a source, intervened mediators and a downstream response. A direct source effect and an effect passing through a hidden mediator gate can produce identical responses under control and all permitted single knockouts. Knocking out an appropriate pair breaks that agreement: the gate turns off while the source remains active (Fig. 2a). The joint intervention reveals a difference that additional observations of the same single knockouts cannot resolve.

We compared two sets of joint measurements while keeping the number of conditions, observations and appearances of every endpoint identical. Both excluded the same four query pairs (Fig. 2b). In the comparison set, four possible mechanisms generated identical training distributions but disagreed on the requested partner contrast. This imposes an estimator-independent squared-error floor of 0.0625. Repeating those conditions more precisely preserves the ambiguity. The informative set instead distinguished the mechanisms responsible for the different query answers (Fig. 2c).

Changing only the measurement set reduced target error by 92.84% for the same least-squares procedure (Fig. 2d). A strong generalized least-squares estimator also benefited from the informative measurements. The gain therefore reflects what the experiments reveal about the query, rather than an advantage exclusive to one estimator. Identification depends on the specified mechanism family; allowing additional simultaneous gates restores ambiguity, as shown by a counterexample in Supplementary Note 2.

The experiment shows why endpoint coverage and observation count alone do not determine the information available for an unmeasured combination. Which interventions are measured together can matter even at the same budget. The biological analyses next ask how WitnessCell uses available combination measurements, first to improve complete predictions and then to learn additional partner-dependent responses.

### WitnessCell leads aggregate evaluation of unmeasured combinations

We evaluated the released core in the genetic-combination track of scPerturBench, using its four datasets and original six-metric aggregation.[21] The comparison included fifteen eligible comparator entries, including simple references, alongside WitnessCell. The complete track combines double perturbations and unseen singles; we also evaluated the 540 double-perturbation records separately, retaining the same methods, scores and aggregation rule. These datasets include combinatorial expression, CaRPool, primary T-cell and direct-capture perturbation measurements.[9,28,10,29]

WitnessCell ranked first in both the complete track and the double-only subset. For doubles, its mean operation rank was 3.515, compared with 5.150 for the next-ranked method, Scouter.[17] The paired difference had a 95% cluster-bootstrap interval of −2.117 to −1.141 (Fig. 3a,c). All fifteen comparator differences had pointwise intervals below zero. WitnessCell also ranked first by point estimate when neither, one or both query endpoints had been seen in training (Fig. 3b). These are decompositions of the same scoring archive, with pointwise rather than simultaneous uncertainty statements; complete rankings and intervals are in Supplementary Tables S25–S26.

The aggregate lead did not extend to every dataset or metric. WitnessCell led the combined evaluation in three datasets and ranked fourth in Schmidt. Its native-scale MSE was lower than Scouter's in Norman and Replogle_exp6 but higher in Wessels and Schmidt (Fig. 3d). Wasserstein and common differential-expression rankings were also weaker, and the linear model led on unseen singles. These differences show why the aggregate result should be read alongside the underlying response errors. The benchmark's mean-based adapter evaluates selected distributional metrics without establishing that WitnessCell predicts complete cell-state distributions.

Additional analyses examined where the core's gains arose. Improvements persisted after removing the directly manipulated RNA coordinates, showing that prediction benefited downstream readouts. Holding the nonlinear baseline fixed and increasing the available Wessels combination measurements improved complete-response accuracy (Supplementary Fig. S3). The core therefore uses measured combinations to refine predictions beyond its single-response composition. Full effect sizes and the separately defined training-mean reference analysis are retained in Supplementary Note 15. Historical scores for the official linear and training-mean entries differ for an unresolved reason; excluding either or both leaves WitnessCell first under the unchanged aggregation rule (Supplementary Table S31).

The same saved predictions also confirmed the endpoint identity above: residual transfer left the projected partner error unchanged within numerical precision (Fig. 1d; Supplementary Table S9). Thus, a useful improvement in complete prediction can occur without an additional partner correction. This observation motivates a direct test of whether an explicit partner learner improves unmeasured functional responses.

### Partner learning improves functional-screen completion

Growth measurements test the added partner learner against a directly measured cellular phenotype. Using the Horlbeck genetic-interaction screen,[11] WitnessCell fits a baseline to permitted single and combination measurements from each repeat. A shared, signed low-rank matrix then predicts the residual growth response. The primary correction uses rank one; a more flexible spectral model provides a secondary comparison.[30] Both are selected using training combinations and evaluated against their corresponding refitted baseline. Fitness prediction already has precedents, including GEARS;[16] the question here is whether an explicit partner correction improves on a baseline that already uses combination measurements.

In K562, increasing the available combination measurements improved both baseline accuracy and the added correction. At high support, the primary correction reduced complete-response error by 11.03% and partner error by 11.68% on fixed held-out pairs (Fig. 4b). At low support, it gave little complete-response benefit and no partner benefit. Increasing the measured pairs changes both sample size and the pattern of shared endpoints; this experiment therefore measures the return from a more extensive partial screen, without isolating those two effects. Detailed budgets and both model variants are reported in Supplementary Note 7.

With the procedure fixed before Jurkat fitting, the primary correction reduced growth-response error by 6.43% across 617 held-out pairs and partner error by 6.18% (Fig. 4c,d). It improved complete-response prediction in both measured repeats. The model was refitted on Jurkat measurements covering approximately 80% of possible pairs among the included genes. This tests transfer of the fitting procedure between cellular environments within one study. The demonstrated use is completion of an already substantially measured screen; the training fraction is neither a validated minimum requirement nor an estimate of experimental savings.

The TTI2/ACTR10 backgrounds and PGK1/OGFOD1 partners provide a concrete example. Their measured repeat-mean growth contrast was −0.0581. The partner correction shifted the baseline prediction from −0.0233 to −0.0435, closer to the measured value (Fig. 4e,f). Because the four-corner contrast cancels contributions depending only on an individual endpoint, this change shows how the added learner adjusts the predicted effect of exchanging partners across backgrounds. It illustrates the response assessed in the complete held-out test. The example-selection rule, both repeats and every eligible continuation are retained in the figure legend and Supplementary Table S35.

The functional interface implements this use directly: researchers provide repeated single responses, measured pair responses and identities of unmeasured pairs, and receive the baseline, partner correction and complete prediction for each query. The supplied example refits the native procedure without reading query outcomes and reproduces its archived predictions. Researchers can therefore complete the tested kind of partial screen while inspecting which predictions changed through partner learning.

### Readout shrinkage reduces adverse RNA corrections

The RNA extension asks whether training measurements can identify which transcript corrections to retain. We evaluated it on the matched CaRPool development panel.[28] Whole combinations were held out, and eleven four-pair rectangles were used to compare predictions from the same fitted model. The baseline already included nonlinear composition and endpoint refinement. The added kernel shares residual information between combinations with similar single responses and removes endpoint effects before transfer, allowing it to change the partner contrasts left unchanged by the core's endpoint residual.

To regulate the correction for each transcript, we split permitted training cells into disjoint halves and compared their responses after removing endpoint effects. A transcript with weak agreement received a smaller correction. This rule uses training measurements before scoring any query. Agreement between cell halves measures sampling consistency within an experiment; shared guide or preparation effects can persist in both halves. The weights therefore regulate the fitted prediction without establishing reproducibility across independent biological preparations.

The resulting predictor, R, reduced held-out rectangle error by 15.96% relative to its baseline and by 6.94% relative to a training-selected uniform shrinkage control (Fig. 5b,c). Shrinking every transcript by the same amount could not account for the full improvement. An error-budget analysis explains the difference: transcript-specific shrinkage retained most of the unweighted correction's helpful changes while removing most of its harmful changes (Fig. 5d). The complete positive, adverse and net contributions, matched neural comparisons and individual-seed results are given in Supplementary Notes 6, 13 and 15.

The benefit was concentrated. Ten transcripts, including S100A9, S100A8, S100A12 and LYZ, accounted for over 90% of positive error reductions. Removing that fixed set or standardizing by training-condition variance eliminated the aggregate gain (Fig. 5e,f). Outside the set, shrinkage substantially reduced the harm caused by the unweighted correction but left the net gain close to zero and slightly negative. These results locate the useful correction in a small subset of measured responses rather than establish broad recovery of transcriptome-wide partner structure.

Frozen checks in Dixit and Combi-seq did not establish an additional partner gain, despite useful complete-response prediction in the Dixit baseline.[4,31] The RNA analysis thus adds a specific design lesson: a learner that can change partner contrasts still needs measurements that support those changes in the readouts being predicted. In this development panel, training-based shrinkage improved that balance; transfer of the RNA partner increment across sources remains unestablished.

### Further uses distinguish prediction from decision utility

Separate retrospective analyses evaluated risk selection and PairPick partner recommendation (Supplementary Fig. S1). Risk selection retained a subset with lower prediction error. PairPick executed a fixed-objective recommendation task, but its choices largely matched existing alternatives. Moreover, many detected intervention labels could not be matched to the original design table.[32] These analyses show why improved response prediction, lower-risk selection and improved experimental choices require separate evaluation. All tasks, candidate pools, paired comparisons and identity qualifications are retained in Supplementary Notes 8, 9, 13–15.

## Discussion

Combination measurements can improve a model in two distinguishable ways: they can refine contributions associated with individual interventions, or help predict how a response changes with its partner. WitnessCell shows how to connect that distinction to a working predictor. The endpoint residual improves complete responses while leaving a specified partner contrast unchanged. Explicit partner learners can change that contrast, and the functional results show that doing so can improve held-out growth prediction beyond the same fitted baseline. The advance is a constructive link between what a correction can express and what it adds to prediction.

This link provides a practical order for designing combination predictors. First establish which response differences the training experiments can distinguish. Then identify which of those differences a proposed correction can change. Finally, test the correction on held-out combinations against a baseline using the same observations. The controlled causal result addresses the first question within its specified mechanism family; the endpoint identity answers the second exactly for the released residual; the growth and RNA analyses address the third empirically. These distinct tests prevent a gain in overall accuracy from carrying a stronger claim about partner learning than the fitted model supports.

The approach complements strong-baseline comparisons, Systema's analysis of systematic variation and Miller's metric calibration.[22,23,24] It also supplies a question for increasingly powerful representations, including scGPT, scFoundation and Geneformer: which partner-dependent responses does a learned correction improve beyond its baseline?[18,19,20] Projection, kernel regression and matrix regularization provide established mathematical tools. Their use here makes a specific limitation visible and supplies corrections that can overcome it. The biological results determine where those corrections are useful: functional-screen completion with substantial combination support, and concentrated RNA improvements regulated by agreement in training measurements. Broader RNA transfer and accurate functional prediction from very sparse combination data remain open.

For researchers, WitnessCell turns existing measurements into predictions for missing combinations and returns the fitted baseline and correction alongside them. This supports scrutiny of the predicted response, as well as comparison of overall errors. Targeted RNA and multimodal protein screens offer further settings for testing partner-dependent changes,[33,34,35] while choosing informative next combinations could connect prediction to experiment planning.[36,37] These directions contribute to the broader goal of predictive cellular models,[1,2] but require their own held-out tests. The present method delivers a concrete step: learning and testing additional partner responses within a usable combination predictor.
