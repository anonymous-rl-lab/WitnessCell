# Reproduction contents

This directory is the compact, reviewer-facing extraction of `grn_repo_v18`.

The scientific emphasis is the final evidence chain rather than the complete
chronology of every exploratory gate. Historical duplicates are represented by
hash records; the current algorithm, final benchmark, selective analysis and
metric stress test remain executable.

| Component | Included | Excluded |
|---|---|---|
| v14 prediction | source, contracts, condition moments, frozen summaries | duplicate deployment containers |
| scPerturBench | source, data manifest, reference tables, official scores | raw h5ad, old prediction copies |
| selective prediction | full compact Gate 21 directory | none |
| metric calibration | protocol, source, tests, smoke asset, formal tables | four large regenerable Phase-M contracts |
| named-model gate | code, independent audit, figures and compact results | raw training archives/logs |
| theory | geometry, exact-risk and estimated-risk code/results | compiled caches |

See `ASSET_POLICY.md` for the exact slim-release boundary.
